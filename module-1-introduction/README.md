# Module 1 — Introduction

## What you're building

A tiny program that prints your CYOA game title and asks the player for their name. You'll use that name in a welcome message so the game feels personal.

## Why it matters

This module covers **`print()`** and **`input()`** — how Python talks to the player and reads what they type. Every later module builds on this foundation.

## Acceptance criteria

- [ ] Running `game.py` prints a game title you chose (not a placeholder).
- [ ] The program asks the player for their name using `input()`.
- [ ] The program uses the player's name in at least one printed message.
- [ ] All tests in `test_module1.py` pass.

Before you open your PR, write 2–3 sentences answering:

> How do `print()` and `input()` work together in your program? What happens if the player presses Enter without typing a name?
